## ✨ Возможности

| | |
|---|---|
| 📊 **Бар** | рабочие столы, часы, плеер, трей, сеть, звук, батарея; **подстраивается под ширину экрана** — на обычном мониторе полный, на среднем без второстепенного, на узком (телефон как второй монитор) только значки |
| 🧰 **Док** | закреплённые и запущенные приложения, значки Orbit, виджеты |
| 🚀 **Лаунчер** | поиск программ и калькулятор, виды «список», «сетка», Spotlight |
| 🎛 **Пункт управления** | плитки (крупные и малые, свой порядок), звук, яркость, плеер, питание, профили; вид (стиль, место, ширина, высота) общий со шторкой «Оформление» |
| 🎨 **Оформление** (`SUPER+X`) | шаблоны «Классика», «Жидкое стекло», iOS, Аврора, EchoStar, праздничные; палитры, акцент, цвет из обоев; на широком экране «Темы» — в три колонки |
| 🖼 **Мастер обоев** | свои папки, интернет (Wikimedia, Bing, Wallhaven и др.), смена по таймеру, перетаскивание файлов в окно, поиск по названию |
| 🎬 **Запись экрана** | видео MP4 или GIF, звук системы / микрофон / оба, частота, качество, курсор, отсчёт; редактирование готовых записей |
| 📋 **Буфер обмена** | история с поиском, закрепление записей (cliphist) |
| 🔊 **Звук** | выход, вход, громкость каждого приложения, проверка каналов и микрофона |
| 📈 **Диспетчер задач** | процессы, нагрузка, память, диски, сеть, видеокарта |
| 📦 **Программы** | каталог приложений: установка, удаление, обновление, поиск в репозиториях и AUR |
| 🧩 **Виджеты** | часы, погода, календарь, заметки, таймер, плеер, лимиты Claude, устройства Orbit |
| 🌌 **Живые фоны** | звёздное небо, космос (солнечная система), орбиты окон |
| 🔒 **Экран блокировки** | несколько стилей, уведомления, плеер |
| 🪐 **Orbit** | значок и лента устройств, плитка, виджет — связь с телефоном (приложение [NameLess Orbit](../nameless-orbit)) |
| 🌐 **Языки** | русский и English, выбор при первом запуске |

## 📦 Установка

**Вместе со сборкой glassrice** (рекомендуется): конфиги, шрифты, зависимости и тема ставятся одной командой.

```bash
git clone https://github.com/thecylindr/glassrice.git && cd glassrice
./install.sh                 # меню; для оболочки достаточно «Оформление целиком»
```

**Вручную** — только оболочка:

```bash
mkdir -p ~/.config/quickshell
cp -r nameless ThemeDrawer ~/.config/quickshell/
qs -c nameless &             # оболочка
qs -c ThemeDrawer &          # шторка «Оформление»
```

**Нужно:** `quickshell`, Hyprland (или driftwm), PipeWire, шрифт Nerd Font (значки). Для отдельных частей: `cliphist` и `wl-clipboard` (буфер), `gpu-screen-recorder` или `wf-recorder`, `slurp` и `ffmpeg` (запись), `hyprpicker` (пипетка), `playerctl`, `NetworkManager`, `awww` (обои с плавной сменой).

## ⚙️ Настройка

- **Язык** — при первом запуске, потом: «Пункт управления» → значок вида (󰕮) → «Язык».
- **Вид шторки** — тот же значок: стиль (окно или шторка), где открывается, ширина, число плиток; общий для «Оформления» и пункта управления.
- **Плитки и виджеты** — карандаш в шапке пункта управления; «Функции» — что включено и как нагружает систему.
- **Режим производительности** — «Авто» включает экономный режим на батарее (живые фоны 30 кадров, реже опрос).
- **Файлы настроек**: `~/.config/glassrice/nameless.json` (док, виджеты, плитки, запись, язык) и `~/.config/glassrice/drawer.json` (вид шторок).

## 🎹 Команды IPC

```bash
qs -c nameless ipc call control toggle        # пункт управления
qs -c nameless ipc call wallpapers toggle     # мастер обоев
qs -c nameless ipc call recorder toggle       # окно «Запись экрана»
qs -c nameless ipc call record screen         # начать/остановить запись экрана
qs -c nameless ipc call audio toggle          # окно «Звук»
qs -c nameless ipc call orbit toggle          # лента устройств Orbit
qs -c nameless ipc call widgets edit          # правка виджетов
```

## 🌐 Языки

Тексты в коде — русские, обёрнуты в `Tr.t("…")`; английский берётся из `nameless/i18n/en.json` («русская строка» → «английская»). Нет строки в словаре — остаётся русская, интерфейс не пустеет. Переключение — на лету. Хотите помочь с переводом — правьте `en.json`.

## 🗂 Структура

```
nameless/              сама оболочка
    shell.qml          точка входа: окна загружаются лениво (Lazy)
    Bar.qml  Dock.qml  Launcher.qml  ControlCenter.qml  Wallpapers.qml  RecorderPanel.qml …
    Config.qml         настройки (Singleton), Tr.qml — язык, Theme.qml — оформление
    i18n/en.json       английский перевод
ThemeDrawer/           шторка «Оформление» (отдельный процесс)
```

## 🧯 Если что-то не так

- Лог оболочки: `qs -c nameless log`.
- После правки файла Quickshell перечитывает его сам; ошибки QML видны в логе.
- Вопросы по сборке — в [FAQ glassrice](https://github.com/thecylindr/glassrice/blob/main/FAQ.md).
